# 0014 — App icon: ship the design handoff's PNGs, drop the Node icon generator

**Status:** Accepted, 2026-10-27

## Context
The old icon (a green square with a white house and check mark) was generated by `npm run icons` (`@vite-pwa/assets-generator`, `pwa-assets.config.ts`) from **one** SVG, `public/favicon.svg` ([chapter 11](../learning/11-pwa-install-on-iphone.md)). The new icon from `docs/wg-app-icon/` (an orange sponge with a "done" bubble on ink `#1D1838`) has **two** sources: the full `icon.svg` and a simplified `favicon.svg` that stays readable at 16 px. The handoff also brings finished PNGs, a preview of them and its own render script (`render_icons.py`, Python + Playwright/Chromium).

Alternatives considered:
- **Keep the Node generator, point it at `icon.svg`**: no Python needed. But it takes only one source image, so the simplified favicon PNGs would sit outside it. Its renderer (sharp) could also differ slightly from the approved preview.
- **Ship the handoff files, regenerate with `render_icons.py`** (chosen).

## Decision
Copy the handoff PNGs and `favicon.svg` into `public/` under the handoff's file names (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`, `favicon-32.png`, `favicon-16.png`). Remove `pwa-assets.config.ts`, the `icons` script and `@vite-pwa/assets-generator`, so nobody can regenerate the old file names from the wrong SVG. The source of truth is `docs/wg-app-icon/icon.svg` + `favicon.svg`. To change the icon: edit the SVG, run `python3 docs/wg-app-icon/render_icons.py docs/wg-app-icon`, copy the PNGs into `public/`.

While at it, the leftover colours from the old design now use Design 3's `--bg` ([ADR 0012](0012-design-3-knautsch-drehscheibe.md)): manifest `theme_color`/`background_color` `#f4f2fb`, `<meta name="theme-color">` `#f4f2fb` light / `#121022` dark.

## Consequences
- ➕ What ships is exactly what the designer previewed; the favicon is the simplified one.
- ➕ One fewer dev dependency (~830 lines less in `package-lock.json`).
- ➖ Regenerating needs Python + Playwright, and copying into `public/` is a manual step.
- ➖ iOS caches Home Screen icons: every flatmate has to remove the app and add it again to see the new icon. That also wipes the app's own storage, so everyone logs in and turns notifications on again. Best done before the Phase 4 push test matrix.
